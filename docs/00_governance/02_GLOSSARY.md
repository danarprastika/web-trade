# System Glossary

> Status: FINAL FROZEN BASELINE v1.0 — subordinate to FINAL_SPECIFICATION/.

## Purpose
Provide canonical meanings for terms used across documents.

## Core terms

Signal = strategy intent; OrderIntent = executable request awaiting governance; Order = broker-facing lifecycle object; Fill = authoritative execution event; RiskDecision = governed risk result; Reconciliation = comparison of internal and external trading state.

## AI terms

Agent = runtime AI worker; Model = model artifact/provider version; Prompt = versioned instruction artifact; Tool = explicitly permissioned capability; Master AI = coordinator, not unrestricted trader.

## Environment terms

Research, Test, Staging, Shadow, Demo/Paper and Live are distinct environments with separate authority and credentials.
