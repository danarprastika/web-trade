# Enterprise Document Change and Baseline Control

## Status
Controlled documentation standard.

## Baseline Rules
A baseline is a versioned set of documents, manifests, and evidence references.

Changes require:
1. identified source and affected documents;
2. impact analysis;
3. classification of the change;
4. approval when required;
5. updated traceability;
6. updated manifest/checksums;
7. clear status transition.

Filename order, modification time, or agent preference cannot silently establish normative authority.
