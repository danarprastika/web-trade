# Enterprise Configuration and Asset Management

## Status
Controlled operational standard.

## Managed Assets
- services
- repositories
- databases
- queues/event infrastructure
- deployment environments
- market/account connections
- models and prompts
- provider integrations
- certificates/keys metadata
- critical configuration

## Rules
Configuration affecting authority, risk, market routing, credentials, or financial state must be versioned, reviewed, and auditable.

Secrets are never stored as ordinary configuration values.
