# Enterprise Control Catalog

## Status
Controlled catalog structure. Control values requiring owner decisions remain unapproved until recorded through the applicable process.

## Control Families
| Family | Examples |
|---|---|
| GOV | authority, decision records, exceptions |
| RSK | risk veto, limits, exposure, kill controls |
| SEC | identity, authorization, secrets, security testing |
| DAT | lineage, quality, retention, access |
| AI | model registry, evaluation, prompt governance, agent permissions |
| TRD | order intent, execution, reconciliation, market isolation |
| SRE | availability, observability, incident, recovery |
| SDLC | code review, CI/CD, release, rollback |
| FIN | accounting, P&L, reconciliation, financial evidence |
| VEN | provider certification, third-party risk |
| CMP | jurisdictional obligations and compliance evidence |
| AUD | evidence integrity, records, audit trail |

## Control Lifecycle
Draft -> reviewed -> approved -> implemented -> evidenced -> monitored -> retired.

Controls marked as design intent are not evidence of implementation.
